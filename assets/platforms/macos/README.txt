Install Smpl3D

Drag Smpl3D.app onto Applications.

Updating an older installation

1. Quit the app.
2. Drag Smpl3D.app from this disk image onto Applications and choose Replace.

Some earlier releases were installed as SolveCraft.app. Move that one to the Trash
once Smpl3D.app is in Applications, and replace any Dock shortcut with the
old name (open Smpl3D.app, then choose Options > Keep in Dock).

Designs saved as .smpl3d or .solvecraft still open, and Smpl3D copies
your settings and recovery files from the old SolveCraft folder on its first
launch. New designs are saved as .sc.
